# Gym Mapa

App de Android para ver ejercicios, qué músculos trabajan y crear rutinas.

- Más de 40 ejercicios con animación y mapa de músculos
- Generador de rutinas según tus días, tiempo, objetivo, nivel y equipo
- Modo entrenamiento con temporizador de descanso y registro de pesos
- Modo claro y oscuro
- Todo se guarda solo en tu teléfono: sin cuenta y sin internet

## Descargar

Descarga la última versión aquí: **[GymMapa.apk](../../releases/latest/download/GymMapa.apk)**

## Instalar en Android

1. Abre el archivo `GymMapa.apk` en tu teléfono.
2. Si Android lo pide, permite **"Instalar apps de origen desconocido"** para tu navegador o tu app de archivos.
3. Toca **Instalar**.

Para actualizar, instala el APK nuevo encima del anterior. Tus rutinas se mantienen.

## Cómo se construye

Cada cambio en la rama `main` hace que GitHub Actions construya el APK y lo publique en **Releases**.
